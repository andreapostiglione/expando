# Expando

Privacy-first text expander for macOS. Users create keyboard abbreviations that expand into snippets, dates, forms, and shell-backed templates — entirely on-device.

## Users

- Solo professionals and small teams on macOS who type the same phrases daily
- Power users migrating from Espanso / TextExpander / Raycast snippets
- Italian-first operators who need reliable non-US keyboard triggers

## Product principles

1. **Local by default** — no account, no telemetry
2. **Trust the tool** — doctor, permissions wizard, self-heal when something breaks
3. **Fast enough to disappear** — expansion should feel native, not “app intervening”
4. **Editor is a product surface** — creating/editing snippets must feel calm and clear

## Primary surfaces

- Menu bar status + actions
- Snippet editor (list + detail)
- Fuzzy search picker
- Onboarding / permissions
- CLI + hub for power users
